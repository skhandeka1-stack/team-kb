# Estimate the value of changing task order

For a workflow where similar tasks may share setup, first distinguish tasks from the same case from tasks on different cases with similar work. A scheduler can create some cross-case pairings, subject to eligibility and deadlines.

Compare the same worker under comparable conditions. Check time of day, task complexity, and rework. Split the comparison group by what differs and report how many observations in each group overlap under the comparison rules. If overlap is sparse, report the evidence gap. A following-task comparison can help detect a pattern that appears in both directions.

Estimate the opportunity separately from the observed time difference. With six eligible tasks across three categories in an invented pool, perfect grouping creates at most three within-category transitions. Subtract transitions already present. Then constrain the remainder by availability, wait-time limits, and staffing. Test feasible routing before projecting realized impact.
